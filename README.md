# 食物重量記錄

可加入主畫面的靜態 PWA，使用 GitHub Pages HTTPS 網址。

## 功能
- 自訂單位、食物模板、快速加減重量或個數。
- 品項資料庫及當餐／日誌熱量試算，未設定熱量的品項不計入合計。
- 體重、體脂、餐別與備註，可複製日誌。
- 生理期日曆、自動備註及下次日期預估。
- 兔子 App 圖示與離線快取。

## 手機使用
在 Safari 或 Chrome 開啟正式網址，透過分享或瀏覽器選單「加入主畫面／安裝應用程式」。首次使用需連線載入頁面。

## 資料儲存
資料只儲存在目前瀏覽器的 localStorage，不會上傳 GitHub，也不會跨裝置或網址同步。本機預覽的資料不會自動搬到正式網址。清除網站資料會刪除記錄，目前尚無匯出備份功能。

日誌目前保存一份表單，切換日期並不是多日日誌歷史帳本。已套入餐別的熱量保存為日期與內容相符的快照；手動編輯後需重新套用。

熱量依填寫資料試算；生理期預估僅供參考，不作為避孕或排卵判斷依據。
