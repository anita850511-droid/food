# 食物日記 App

GitHub Pages 靜態 PWA，支援自訂單位、食物模板、品項資料庫、當餐與日誌熱量、體重／體脂、按日期儲存的日記與折線圖、生理期紀錄和預估。

## 更新方式
將此資料夾所有檔案一次上傳到網站根目錄，不要在修改進行中複製中間版本。新版使用 `food-tracker-v6` 離線快取；更新後重新整理網頁。不要為了更新而清除網站儲存資料。

## 資料與備份
資料先存目前瀏覽器 localStorage。進入「同步與備份」下載 JSON 備份，或還原備份。原本單份日誌會自動搬入其日期，之後每個日期獨立保存。圖表使用有效體重／體脂數字，不把空白視為零。

## Google Drive
網頁端已支援 OAuth 授權、私人 App 資料區、版本快照與衝突確認。需先依 GOOGLE-DRIVE-SETUP.md 設定自己的 Google OAuth Client ID；尚未完成設定前不會同步。此版本未在真實 Google 帳號完成端到端驗證。

網頁開啟且授權有效時才會自動同步。授權到期需重新連接，不是背景常駐服務。相同 Google 帳號與 OAuth 專案可跨裝置載入資料。任何登入 token 都不會寫入備份或原始碼。

## 手機使用
透過 Safari／Chrome 的「加入主畫面／安裝應用程式」使用。App 圖示是兔子，頁首保留食物裝飾。首次需連線快取；Google 登入與同步需網路。

熱量依使用者填寫資料試算。生理期預估僅供參考，不作為避孕或排卵判斷依據。
